# Patterns / Padrões

## English
- **Release flag** — hide unfinished work in production.
- **Experiment flag** — A/B or multivariate tests.
- **Ops flag** — kill switch / degrade gracefully.
- **Permission flag** — entitlement-style access (use carefully; not a security boundary alone).

Evaluation context often includes user id, plan, locale, and percentage rollout.

## Português
- **Release flag** — esconder trabalho incompleto em produção.
- **Experiment flag** — testes A/B ou multivariados.
- **Ops flag** — kill switch / degradação graciosa.
- **Permission flag** — acesso estilo entitlement (use com cuidado; não é boundary de segurança sozinha).

O contexto de avaliação costuma incluir user id, plano, locale e percentagem de rollout.
